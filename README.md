# 🥁 JavaScript Drum Kit

Projeto interativo de bateria desenvolvido com HTML, CSS e JavaScript.

## 🚀 Funcionalidades
- Reprodução de sons ao pressionar teclas
- Interação via teclado
- Feedback visual ao tocar

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript

## 🎯 Objetivo
Projeto criado para praticar manipulação de DOM e eventos com JavaScript.

## ▶️ Como executar
Abra o arquivo index.html no navegador
